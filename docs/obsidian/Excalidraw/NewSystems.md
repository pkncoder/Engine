What is a Directed Acyclic Graph (DAG), and why use it? ^QAiQNHLb

A DAG is a form of a graph with specific rules:
  - Directed - It only moves in one direction
  - Acyclic - The graph cannot loop into itself

We use this to have a stable render execution.
Having the same execution and passing of resources
every frame (unless changed). ^xYJl4rau

What are the 3 different types of creating a render graph? ^JvQzZoSD

How you store your render graph in memory is important, as it 
defines the CPU overhead, storage needs, and render flexibility.
  1. Static - Built once | low CPU overhead | no flexibility
  2. Dynamic - Built every frame | high CPU overhead | maximum flexibility
  3. Hybrid - Built only when changed | optomized CPU overhead | high flexibility

With this, also comes differing levels of complexity:
  - Static is very simple, and requires the least amount of work
  - Dynamic is simple as well, as the only complexity is making sure
       everything will cleanly be destroyed and created
  - Hybrid is a much more complex system, as you need to figure
       out when to compile. However, it can make a very optimized setup

The goal for my render graph is to create a hybrid graph, but it will start
as a dynamic graph for now. ^xiqtMxXU
